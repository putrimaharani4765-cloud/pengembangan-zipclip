# Desain dan Dokumentasi Visual

Simpan berkas desain dan dokumentasi visual pada folder ini:
- `foto-prototipe/` — foto prototipe fisik dari berbagai sudut;
- `gambar-komponen/` — gambar masing-masing komponen;
- `skema/` — skema susunan komponen dan mekanisme kerja.

Cantumkan keterangan, tanggal, dan versi pada nama berkas. Contoh: `zipclip-prototipe-tampak-atas-v1.png`.

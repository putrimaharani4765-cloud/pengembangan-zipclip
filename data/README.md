# Data Proyek

Pisahkan data mentah dan data hasil analisis. Pertahankan berkas data mentah apa adanya; lakukan pengolahan pada salinannya. Sertakan satuan, tanggal pengujian, kode sampel, dan keterangan kondisi pengujian.

Jangan mengunggah data yang belum diperoleh atau membuat angka simulasi seolah-olah merupakan hasil eksperimen.

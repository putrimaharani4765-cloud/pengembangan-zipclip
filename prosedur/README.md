# Prosedur Kerja dan Pengujian

Dokumen prosedur perlu diperbarui sesuai metode yang benar-benar disepakati dan dilaksanakan. Catat setiap perubahan metode beserta tanggal dan alasannya.

Ruang lingkup prosedur:
1. Persiapan model kulit sintetis dan sampel.
2. Persiapan prototipe ZipClip.
3. Simulasi fungsi penutupan celah.
4. Pengujian fleksibilitas.
5. Pengujian ketahanan terhadap kelembapan.
6. Pengamatan lapisan biomaterial (homogenitas, pH, dan perubahan visual).
7. Pengujian antibakteri sebagai pengujian lanjutan setelah metode, kontrol, dan fasilitas dipastikan.

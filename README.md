# Pengembangan ZipClip

Repositori ini digunakan untuk mendokumentasikan proyek **Pengembangan ZipClip Berbasis Biomaterial Alami dan Sintetis sebagai Alternatif Penutupan Luka Robek Ringan**.

## Deskripsi singkat
ZipClip merupakan prototipe alternatif penutupan luka robek ringan yang menggabungkan komponen perekat dan polimer sintetis dengan lapisan biomaterial alami. Komponen yang direncanakan/digunakan dalam rancangan meliputi medical adhesive tape, polyurethane (PU) film, polyester strip dengan mekanisme pengunci, serta campuran gel lidah buaya dan madu dengan perbandingan 2:1.

## Tujuan
Mendokumentasikan desain, prosedur kerja, data pengujian, pengolahan data, dan perkembangan proyek ZipClip.

## Ruang lingkup pengujian
Pengujian prototipe direncanakan pada model kulit sintetis atau elastomer, bukan pada luka manusia. Pengujian mencakup:
- fungsi penutupan celah dan mekanisme pengunci;
- fleksibilitas prototipe;
- ketahanan perekat terhadap kelembapan;
- karakteristik lapisan biomaterial, termasuk homogenitas dan pH;
- pengujian antibakteri sebagai tahap lanjutan apabila metode dan fasilitas telah ditetapkan.

Hasil pengujian pada model sintetis tidak dapat digunakan untuk menyimpulkan keamanan atau efektivitas klinis pada manusia.

## Cara menggunakan repositori
1. Baca dokumen pada folder `dokumentasi/` untuk memahami proyek.
2. Simpan foto prototipe, gambar komponen, dan skema pada folder `desain/`.
3. Simpan data mentah tanpa mengubah berkas asli pada `data/data-mentah/`.
4. Simpan hasil olah data dan grafik pada `data/hasil-analisis/`.
5. Gunakan dokumen pada `prosedur/` sebagai catatan metode dan pelaksanaan pengujian.
6. Cantumkan sumber ilmiah dan standar pada `referensi/`.

## Status
Repositori ini merupakan kerangka dokumentasi proyek. Data hasil pengujian hanya ditambahkan setelah pengujian benar-benar dilakukan. Jangan mengisi data contoh seolah-olah merupakan hasil eksperimen.
